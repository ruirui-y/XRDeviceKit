### 为什么刷新率会错

App 枚举到的屏是这样的（`adb logcat -s XRBridge`）：

```
display 内置屏幕 1200x720 active=72.00001
display txr:1794994498589 1200x720 active=60.0
```

内置屏被虚拟化成 1200×720 的 2D 面板，当前跑到 72——所以 `getDefaultDisplay().getRefreshRate()` 只能拿到 72。而这块屏 `getSupportedModes()` 里有 90 的模式，取最大值才等于面板能力。

**代价**：这个节点返回的是"设备支持的最高刷新率"，不是"当前 2D 面板实际跑的帧率"（那个是 72）。
