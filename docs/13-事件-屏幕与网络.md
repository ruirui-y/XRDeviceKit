## 1. 这一阶段要做什么

之前所有节点都是"主动查"——轮询才知道屏幕灭了、网断了。这一轮做**事件**：Android 一发生就推到蓝图，不用每帧查。

两个事件：

| 事件 | 触发 |
|---|---|
| `OnScreenStateChanged(bool)` | 亮屏 / 灭屏 |
| `OnNetworkChanged(bool)` | 默认网络连上 / 断开 |

---

## 2. 怎么做的

### 2.1 这是插件里唯一一处 Java 主动调 C++

```
Android 广播（ACTION_SCREEN_ON/OFF）
   ↓
Java: XRBridge 里的 BroadcastReceiver
   ↓  调用 native 方法
C++: Java_com_xrdevicekit_bridge_XRBridge_OnScreenStateChanged（Java 线程）
   ↓  AsyncTask 切 GameThread
C++: UXRDeviceKitEventSubsystem 广播蓝图多播委托
   ↓
蓝图: Bind 到 OnScreenStateChanged 的事件
```

### 2.2 绑定方式：命名约定，不用 RegisterNatives

Java 侧只写声明：

```java
public static native void OnScreenStateChanged(boolean isOn);
```

C++ 侧导出同名符号：

```cpp
extern "C" JNIEXPORT void JNICALL
Java_com_xrdevicekit_bridge_XRBridge_OnScreenStateChanged(JNIEnv*, jclass, jboolean)
```

JVM 加载 `libUnreal.so` 时按 `Java_<包名>_<类名>_<方法名>` 找符号。**名字错一个字符，编译能过、真机才崩**，这是这条路唯一的坑。

### 2.3 两层回调，别混

| 层 | 是什么 | 谁触发 | 线程 |
|---|---|---|---|
| JNI 层 | `native` 方法 | Java 广播 | Java 主线程 |
| UE 层 | `BlueprintAssignable` 多播委托 | 我们广播 | GameThread |

### 2.4 为什么必须切线程

Java 回调在 Android 主线程，那里没有 UObject 的上下文，直接访问会崩。所以：

```cpp
AsyncTask(ENamedThreads::GameThread, [bScreenOn]()
{
    if (UXRDeviceKitEventSubsystem* Self = CurrentInstance.Get())
    {
        Self->OnScreenStateChanged.Broadcast(bScreenOn);
    }
});
```

用弱指针 `CurrentInstance`，子系统销毁后回调自动变成空操作。

### 2.5 新增的东西

| 文件 | 内容 | 行数 |
|---|---|---|
| `Public/XRDeviceKitEventSubsystem.h` | 两个多播委托 + 子系统接口 | 46 |
| `Private/XRDeviceKitEventSubsystem.cpp` | 生命周期、JNI 符号、线程切换 | 95 |
| `XRBridge.java` | 广播接收器、网络回调、两个 native 声明 | +150 |
| `XRDeviceKitJava.cpp` | `CallVoid` + 4 个开关函数 | +45 |
| `XRDeviceKit_APL.xml` | 加 `ACCESS_NETWORK_STATE` 权限 | +4 |

## 3. 写完为什么不是理想效果

这轮**没有崩溃**，代码一次编译通过。真机第一次测试时头显掉线（`adb devices` 为空），事件一条都没抓到；重连后按下面的命令跑，四类事件全部到齐。

需要注意的两点：

1. **网络回调依赖权限** —— `registerDefaultNetworkCallback` 需要 `ACCESS_NETWORK_STATE`，普通权限（安装即授予），清单漏了会静默失败。
2. **广播在后台时可能不触发** —— App 被系统冻结时 `BroadcastReceiver` 仍会调到 Java，但引擎暂停期间 `AsyncTask` 要等恢复才执行。

### 蓝图怎么用

```
BeginPlay
  └─ Get Game Instance Subsystem (XRDeviceKitEventSubsystem)
      ├─ Bind Event to On Screen State Changed → 自定义事件（参数 bScreenOn）

```

不需要手动 `StartWatching`——子系统初始化时自动开监听，销毁时自动关。
