## 三、怎么测

### 1. 契约测试（编辑器，10 秒）

```powershell
& "C:\Program Files\Epic Games\UE_5.5\Engine\Binaries\Win64\UnrealEditor-Cmd.exe" `
  "C:\Users\Mars\UE5Project\XRDeviceKitDemo\XRDeviceKitDemo.uproject" `
  -ExecCmds="Automation RunTests XRDeviceKit;Quit" -unattended -nop4 -nosplash -nullrhi -log
```

**结果看 `Saved/Logs/XRDeviceKitDemo.log`，不看 stdout**，搜 `Test Completed`。退出码 0 才算过。

### 2. APK 检查（打包后，2 秒）

```powershell
pwsh Tools/verify_apk.ps1
```

检查 `classes*.dex` 里的 Java 符号、`ActiveUPL.txt` 里的 UPL 记录。退出码 0 = 全过。

### 3. 真机冒烟

冒烟测试在 Development 包默认开启，装包后 3 秒自动跑：

```powershell
adb install -r Binaries/Android/XRDeviceKitDemo-arm64.apk
adb push Binaries/Android/main.1.com.YourCompany.XRDeviceKitDemo.obb /sdcard/Android/obb/com.YourCompany.XRDeviceKitDemo/
adb shell svc power stayon true
adb shell input keyevent KEYCODE_WAKEUP
adb shell monkey -p com.YourCompany.XRDeviceKitDemo -c android.intent.category.LAUNCHER 1
adb logcat -d | findstr "SMOKE|"
```

输出每行一个 `SMOKE|节点名=值`，共 50 行（48 个值 + 3 个标记行）。

**头显睡着时 `am start` 会被拒（error 102）**，必须先用 `svc power stayon true` + `KEYCODE_WAKEUP`，或者用 `monkey` 拉起。

正式出包前把 `Config/DefaultGame.ini` 里的 `SmokeTestOnStartup` 改成 `False`（Shipping 默认已关）。

## 五、已知限制

| 限制 | 原因 |
|---|---|
| 亮度只能改本 App | 改整机要 `WRITE_SETTINGS` |
| 刷新率是能力值 | 返回面板支持的最高值，实际帧率看 `GetRenderFPS` |
| 存储是分区容量 | 读 `/data`，不是标称容量（P1Max 标称 128G，分区 96G） |
| 包相关节点受限 | Android 11+ 只能看到 `<queries>` 声明过的包 |
| 设备 ID 是应用级 | Android 8+ 的 ANDROID_ID 按签名隔离，和 adb 读的不同 |
| CPU 温度可能为 -1 | 部分厂商没配热区文件 |
| 未做跨线程保护 | 节点内部走 JNI，非游戏线程调用需自行 attach |
