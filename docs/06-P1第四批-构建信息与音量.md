## 2. 怎么做的

### 2.1 本轮 12 个

| 分类 | 节点 | 底层 |
|---|---|---|
| 设备构建信息 | `GetManufacturer`、`GetModel`、`GetDeviceName`、`GetSupportedABIs` | `android.os.Build` |

| 显示补充 | `GetSystemBrightness`、`IsNightMode` | `Settings.System`、`Configuration.uiMode` |

### 2.2 新增两个通用调用器

上一轮已经按"名字+签名"缓存方法 ID，这轮补两种情况：

```
CallBool("IsNightMode")          → 无参返回 boolean
CallBoolWithInt("SetVolume", N)  → 一个 int 参数返回 boolean
```

加起来一共 6 个：`CallInt` / `CallLong` / `CallFloat` / `CallString` / `CallBool` / `CallBoolWithString` / `CallBoolWithInt`。

### 2.3 `StartApp` 的包可见性

```java
Intent intent = sContext.getPackageManager().getLaunchIntentForPackage(packageName);
if (intent == null) { return false; }
```

Android 11 起，**没在清单 `<queries>` 里声明过的包，这里一律拿不到**，返回 `null`。所以 `StartApp` 返回 `false` 有两种含义：

1. 真的没装
2. 装了但不可见

要让它可用，得在 `XRDeviceKit_APL.xml` 的 `<manifestAdditions>` 里加：

```xml
<queries>
    <package android:name="com.YourCompany.TargetApp" />
</queries>
```

本轮**没有加**，因为目标包名是工程相关的，插件不该写死。等具体工程用的时候再补。

## 3. 写完为什么不是理想效果

这轮编译一次过，但过程中有两处需要记下来。

### 3.1 先把 `IsNightMode` 写成了内联 JNI

第一版直接在手写函数里展开：

```cpp
jmethodID Method = FindBridgeMethod(Env, "IsNightMode", "()Z");
return Method != nullptr && Env->CallStaticBooleanMethod(GXRBridgeClass, Method) == JNI_TRUE;
```

和其他 15 个方法（都是 `return CallInt("...")` 一行）风格不一致。以后看到这里会疑惑"为什么这个特殊"。

### 3.2 `GetSystemBrightness` 只有 getter 没有 setter

看起来像漏写，实际是故意的：

| 操作 | 权限 | 结论 |
|---|---|---|
| 读 `Settings.System.SCREEN_BRIGHTNESS` | 不需要 | 做了 |
| 写 `Settings.System.SCREEN_BRIGHTNESS` | 要 `WRITE_SETTINGS`，得用户去系统设置里手动开 | 不做，等大鹏给不给系统权限再说 |

`WRITE_SETTINGS` 属于特殊权限，不能靠运行时弹窗申请，只能 `Settings.ACTION_MANAGE_WRITE_SETTINGS` 跳过去让用户点。

---

## 4. 怎么定位的

3.1 是回头通读 `XRDeviceKitJava.cpp` 时发现的：16 个函数里 15 个是单行包装，只有这一个展开成 4 行。判断标准很简单——**同类函数形态不一致，就是有问题的信号**。

解决办法是抽一个 `CallBool` 出来，让它也变成一行。

3.2 是写 Java 时查文档确认的：`Settings.System.putInt` 需要 `WRITE_SETTINGS`，而 `getInt` 不需要。为了不让调用方拿到一个"总是失败"的 setter，干脆不暴露。

---

## 5. 怎么解决的

| 问题 | 改法 |
|---|---|
| `IsNightMode` 风格不一致 | 抽 `CallBool`，函数体变一行 |
| 亮度只有读 | 不暴露 setter，注释里写清原因 |
| `StartApp` 可能误判 | 注释和文档里写清"false 可能是不可见"，并给出 `<queries>` 补法 |
